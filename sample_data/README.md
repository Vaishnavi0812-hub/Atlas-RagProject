# Sample corpus: Northwind Logistics

These are fictional enterprise documents for demonstrating ATLAS. All companies, people and figures are invented.

The facts are deliberately spread across files, so answering the key question requires connecting several documents:

> *Which projects could be affected if Vendor Alpha fails to deliver its components, and are any of them tied to contracts expiring soon?*

| File | Format | Key facts |
|---|---|---|
| `vendor-alpha-supply-agreement.md` | Markdown | Vendor Alpha supplies the HX-200 hydraulic actuator for Product X |
| `product-x-technical-specification.txt` | Text | Product X depends on the HX-200; deployed in Project Delta and Project Orion |
| `project-delta-charter.docx` | Word | Project Delta uses Product X and is governed by Contract 123 |
| `contract-123-summary.pdf` | PDF | Contract 123 with Contoso Rail expires 31 December 2026 |
| `q3-2026-procurement-report.md` | Markdown | Vendor Alpha's late deliveries and spend |
| `supplier-risk-policy.md` | Markdown | Single-source supplier policy and ISO 9001 obligations |

The `.docx` and `.pdf` files are generated by `backend/scripts/generate_samples.py`.
